# Step_semester_3

Repository for Step Semester 3 coursework, tracking all live session practices and homework assignments.

## Branch Structure
- **main**: Project overview and documentation.
- **develop**: Base project skeleton.
- **feature/session_1**: Strings and basic control flow.
- **feature/session_2**: Arrays and text processing.
- **feature/session_3**: Object-Oriented Programming (OOP) fundamentals.
- **feature/session_4**: Constructors, 	his(...) chaining, and class design.
- **feature/session_5**: Access modifiers, encapsulation, JavaBeans, and immutability.

Each feature branch organizes code into two packages:
- class_problems: Problems solved during the live class sessions.
